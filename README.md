
# **HUST MSE Tutorial** { .section-page-title }

👋 **Welcome to HUST MSE !**

信息差永远存在。我们希望能够搭建一个平台，帮助同学们获得更广阔的视野，能够更从容地规划和管理自己的大学生活。

## 项目说明

<div class="article-box" markdown="1">

本项目名为 **HUST MSE Tutorial** ，译为华科机械入门手册。

在大学生活里，信息差长期存在于课业、科研、竞赛、校园生活和升学等方面中。HUST MSE Tutorial 希望保存来自往届同学的一手经验，让本科的朋友们能够看到更多路径，并结合自己的情况做出判断。

本网站涵盖大学生活、保研、考研、留学四个板块。

其中保研、考研、留学存放往届朋友们的经验帖，大学生活存放和大学有关的词条，其中经验帖中的关键词也会链接到这些词条。

欢迎新朋友前来探索，也欢迎老朋友积极贡献！

</div>

## 内容原则

<div class="article-box" markdown="1">

- 优先收录真实的一手经历，也请大家在写作、阅读时客观看待作者的观点。
- 不允许冒充官方立场，不允许发布未获授权的个人信息凭据、私密材料或针对具体个人的无依据指控。
- 允许合理批评和负面经验，内容对学校学院的影响由审核把控，审核暂时由网站发起者担任。
- 审核应尊重作者原意，有权改善结构、格式和表达。
- 对不确定和高风险内容采取暂缓公开、退回补充等处理，
- 对内容提供勘误、申诉和撤回渠道。

本站是由学生发起和维护的经验分享项目，所有章只代表作者在特定时间和背景下的个人经历，不代表华中科技大学、华中科技大学机械科学与工程学院、任何实验室或教师的官方网站的观点。

</div>




## 投稿

<div class="article-box" markdown="1">

本站接收大学生活、课程、科研、竞赛、实习、保研、考研、留学和其他与校园成长有关的一手经验，请大家踊跃投稿！

**投稿前请确认：**

- 你是否同意公开发布。
- 你是否匿名。
- 你是否公开联系方式。
- 你的稿件中没有不应公开的个人信息。
- 你的图片、截图、PDF 等内容已检查了隐私信息。
- 你有权提交正文和附件，并已取得其中第三方信息的必要授权。
- 你是否理解稿件可能由网站维护者/本地自动化工具和 AI 辅助检查、排版与润色。
- 你是否已经核对自己帖子中院校、时间、成绩、排名、Offer、论文和其他事实性信息。

**投稿方式**


请打包发送至：**2296937031@qq.com**

建议邮件标题：

```text
[投稿] 栏目 - 文章标题 - 公开称谓
```

邮件正文请写明：

```text
1. 称谓：实名 / 化名 / 匿名
2. 联系方式是否允许公开：是 / 否；允许公开的具体内容
3. 是否允许 AI 做格式和语言润色：是 / 否
4. 图片、截图等信息是否已获得必要授权：是 / 否 / 不涉及
5. 是否同意本站按照当前投稿政策公开发布：是 / 否
```

请勿发送聊天截图、API Key 等隐私内容或与文章无关的内部资料。




**稿件格式：**

支持 Markdown、Word 或纯文本。图片请使用清晰的版本。

投稿人可以直接套用 [经验文章模板](page-templates/article.md)


</div>
