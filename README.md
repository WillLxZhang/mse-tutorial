# [待填写：网站名称]

这是一个 MkDocs Material 静态网站模板。

## 本地预览

```bash
pip install -r requirements.txt
mkdocs serve
```

打开终端显示的本地地址查看网站。

## 生成静态网站

```bash
mkdocs build
```

生成结果会放在 `site/` 目录。

## 维护入口

- 网站配置：`mkdocs.yml`
- 首页：`docs/index.md`
- 关于页：`docs/about.md`
- 投稿说明：`docs/contribute.md`
- 模板文件：`docs/templates/`
