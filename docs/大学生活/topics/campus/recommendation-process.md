# 推免流程 { .section-page-title }

> [校园生活与资源](../../campus-life-and-resources.md)

推免主要包含本院资格确认、接收单位申请与考核、全国推免服务系统确认三个环节。具体时间和材料要求每年可能调整，应以当年学校、学院和接收单位通知为准。

## 保本校

1. **确认本院推免资格**：按机械学院当年通知提交申请和证明材料，参加学院组织的综合评价，关注拟推荐名单及公示结果。
2. **确定培养类型与方向**：了解本校接收推免生的专业、学硕/专硕/直博类型和导师要求；需要提前沟通导师时，可参考[套磁](contacting-supervisors.md)。
3. **完成校内接收程序**：按接收学院通知报名并参加考核，确认拟接收结果。取得本院推免资格和接收学院拟接收资格，两项都需要完成。
4. **在推免服务系统确认**：系统开放后填报本校对应学院和专业，及时确认复试通知与待录取通知。最终录取以全国推免服务系统中的确认结果为准。

## 保外校

1. **确认本院推免资格**：按机械学院当年通知完成申请、综合评价与名单公示。尚未正式确认资格时，可根据预计排名提前准备申请。
2. **准备并投递材料**：关注目标院校的夏令营、预推免和正式推免通知，按要求提交成绩单、排名证明、简历、个人陈述等[文书](documents.md)。导师沟通要求因院系和项目而异。
3. **参加目标院校考核**：完成材料审核、笔试、面试或导师交流，获得拟接收或预录取意向。校方意向仍需通过全国推免服务系统完成正式确认。
4. **在推免服务系统确认**：填报目标院校和专业，及时确认复试通知。通过考核后，在规定时间内接受一份待录取通知；接受后即完成当年推免录取确认。
