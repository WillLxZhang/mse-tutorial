# 套磁 { .section-page-title }

> [校园生活与资源](../../campus-life-and-resources.md)

“套磁”通常指申请者在正式录取前主动联系导师，介绍自己的背景、研究兴趣和申请计划，并询问招生名额、方向匹配或进一步交流的可能性。

联系前应先阅读导师主页、近期论文和招生说明，确认研究方向与自身经历存在具体交集。邮件正文宜简短，说明身份、申请批次、相关经历和联系原因；简历、成绩单等材料按对方要求附上。对不同导师分别撰写与其方向相关的内容，比批量发送同一封邮件更有效。

导师回复、口头意向和课题组交流只能作为申请信息的一部分。报名、考核与录取仍需按院校通知和[推免流程](recommendation-process.md)完成。对方未回复时，可以间隔一段时间礼貌跟进一次，再继续联系其他合适的导师。
