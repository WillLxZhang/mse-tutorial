# 文书 { .section-page-title }

> [校园生活与资源](../../campus-life-and-resources.md)

“文书”是升学申请中用于介绍个人背景、经历与申请动机的材料，常见形式包括个人简历（CV）、个人陈述（PS）、目的陈述（SOP）、研究计划和申请邮件。不同院校、项目对文书名称和内容的要求不同，应以申请通知为准。

准备文书时，可以先整理一份完整的[个人背景（BG）](background.md)素材库，再按目标项目删减和重组。每项经历尽量交代做了什么、承担什么职责、获得什么结果，以及它与申请方向的关系。院校名称、导师姓名、研究方向和项目名称需要逐项核对，避免复用材料时留下错误信息。

申请邮件通常只承担简短介绍和引导阅读附件的作用。需要主动联系导师时，可继续阅读[套磁](contacting-supervisors.md)。
