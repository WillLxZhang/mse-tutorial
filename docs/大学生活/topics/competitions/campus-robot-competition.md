# 校机器人大赛 { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

这是由机械学院牵头主办，学生自主命题与进行组织的一项校级赛事，意在激发大一新生对机器人、对科创的热情与兴趣。每年一度，在秋季学期举办，限定大一新生参赛。每年的赛题、场地、对于机器人的要求不一样。一般为小车类移动机器人，搭载能执行各种任务的执行器，比如机械臂、夹爪等等。一般6人一队。参赛学院不限，往届吸引大量自动化、机械、电信、生科、电气、甚至基础医学等专业的同学参赛。

这项比赛获奖倒是次要的，关键在于让想要参与科创、参加比赛的同学，感受打比赛、做实物的感觉。这次比赛是锻炼自我、结交伙伴的很好机会。笔者个人便在这次比赛结交了之后一起打比赛的很好的哥们，也认识了很多目前还保持联系的年级里一直互帮互助的同学。也是在这一次比赛初步锻炼了答辩、嵌入式、结构等各种能力。总之推荐所有新huster参加。

</div>
