# STAR { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

STAR团队是机械创新基地下的机器人科创团队，由李喜秋老师管理。

## 团队概况

STAR是一个相对自由的团队，或者说更像是一个平台而非“队伍”。大多数团队或以一项赛事为核心导向，或以各类科创项目为目标，这些团队有着明确的主线，在“要做什么”上的选项有限。STAR没有这方面的限制，我们不限制你参加什么比赛，也不限制你做什么项目，可以尽情根据自己的兴趣和规划参与到自己想做的事情中去。

STAR团队的初代队长孙英东学长，本科毕业后创业做产品，并取得了优异的成果，奠定了团队做创新产品的基调。时至今日，他仍会不定期回学校与后辈交流他的公司和团队发展。

因而我们鼓励**做产品**，做自己觉得有趣、有意义的方向和事情。

STAR提供工作地点、各类资料和项目平台。团队成员可以使用工作室的包括螺丝刀、扳手、焊枪等各类工具，并使用划定的工位进行交流备赛；各类技术理论资料会通过培训或线上文档、视频的形式进行传授，在STAR还能交流获取到各类竞赛和项目信息。

## 团队培养

STAR是一个极其适合新生开始科创之路的地方，每一届都有许多厉害的同学从这里走出。

STAR有着成熟的、**新人友好**的培养体系。大多数同学可能因为自己没经验而担忧，但STAR的门槛并不高，从招新开始就会引导每一个同学入手各类科创竞赛所需的基础技能，包括结构三维设计、装配加工、程序编写、通讯控制等等内容，只要付出相应的练习时间和给出一个合格的结果，就基本没有问题。

同时，团队鼓励并指导每一届新生参加**校机器人大赛**。这项比赛对新生来说是绝佳的入门赛事，基本也决定了是否适合这条道路。我们非常看重队员在这项比赛中的表现，备赛期间我们会不遗余力地进行相关培训和指导。

STAR也会组织新生参加一些常规赛事（非强制），如先进成图大赛、智能机器人大赛等等，会邀请学长学姐进行相关经验分享和赛事指导。

## 团队结构

STAR分为技术组和产品组，其中技术组又分出结构组和电控组。

- **结构组**：顾名思义，就是做机械结构的组别，在这里你会学到一切所需要的技能：三维建模设计、机器装配加工等。
- **电控组**：内部还会细分偏硬件和偏算法的方向。硬件指画电路板、接线等与实物关系更重的方向，算法那就是注重代码程序了。
- **产品组**：这个组别稍显特殊，产品组是为项目培养的核心人员，通过学习基础知识，掌握一定实操能力，关注和交流市场、技术、等信息，成为能把控项目方向和推进的核心成员，负责敲定产品方向，统筹项目定义，分工与进度安排，推动技术调研与落地等工作。

做产品是一个系统性的工程，要有能力有想法有毅力和志同道合的伙伴。

## 加入团队

STAR主要通过**秋招**招新，一般招收大一大二的同学。需要注意的是，大部分培训集中在大一学年，大二才加入且之前没有经验的同学考虑到课程压力融入团队会相对困难。我们也会吸纳校机器人大赛中表现优异的同学。

最后，团队内部氛围轻松无压力，每一届都有专门聊天的群供大家加深感情。

欢迎各位同学加入STAR，在这里找到目标与意义，有所收获！
