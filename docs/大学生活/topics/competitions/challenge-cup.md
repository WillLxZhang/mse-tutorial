# 挑战杯 { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)


## 总体介绍
    
<div class="article-box" markdown="1">
“挑战杯”是一项广受认可的赛事，被学校评为A类赛，在保研加分等方面具有很高的认可度。总体分为“大挑”、“小挑”以及各分赛道：“黑科技”专项赛、“揭榜挂帅”专项赛、“人工智能＋”专项赛

</div>

## 大挑与小挑

<div class="article-box" markdown="1">

大挑”：全称为“挑战杯”全国大学生课外学术科技作品竞赛。是由共青团中央、中国科协、教育部、中国社会科学院、全国学联、省级人民政府主办的大学生课外学术科技活动中一项具有导向性、示范性和群众性的竞赛活动。

“小挑”：全称为“挑战杯”中国大学生创业计划竞赛，又称商业计划竞赛。它借用风险投资的运作模式，要求参赛者组成优势互补的竞赛小组，提出一项具有市场前景的技术、产品或者服务，并围绕这一技术、产品或服务，以获得风险投资为目的，完成一份完整、具体、深入的创业计划。


- “大挑”：每两年举办一次，通常在奇数年，校赛在上一年的10月，省赛在当年5-6月，国赛则在10-11月。

- “小挑”：同样每两年举办一次，但在偶数年，校赛在上一年的10月，省赛在当年5-6月，国赛则在10-11月。

</div>

<div class="article-box" markdown="1">

“大挑”主赛道：主赛道作品类别——自然科学类学术论文、哲学社会科学类社会调查报告、科技发明制作。对于主赛道，参赛作品可以是科研成果、科技发明创造、社会调查报告等，考察学生的科技创新能力、对社会问题的关注及其分析解决问题能力‌。分赛道则会具体说明每个赛道的参赛要求。主赛道参赛难度大，认可度很高。

“小挑”：科技创新和未来产业、乡村振兴和农业农村现代化、社会治理和公共服务、生态文明建设和绿色低碳发展、文化创意和区域交流合作。参赛者需要提出一项具有市场前景的技术、产品或者服务，并围绕这一技术、产品或服务完成一份完整、具体、深入的创业计划，注重技术服务与市场的结合。

专项赛道作品类别——“揭榜挂帅”专项擂台赛等。评选流程大致分为：1.选择参赛题目，进行材料准备（一般只需要文书材料，pdf格式的项目书、项目工程文件等）2.提交材料，进行评选，决定是否晋级国赛 3.国赛现场ppt答辩，评选最终奖项。分赛道相对而言难度小一点，一般没有校赛，直接进行晋级国赛的评选，但是对于加分而言各类目前奖项会降一档加分。而且不好说后续会不会逐渐进一步降级，因此后续参赛需要慎重，具体还是要和辅导员、老师等进行沟通。

</div>
