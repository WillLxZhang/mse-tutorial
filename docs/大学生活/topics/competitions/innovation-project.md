# 大创项目 { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

大学生创新创业训练计划（大创）是教育部面向本科生实施的科研训练与实践项目，学生在导师指导下自主完成项目，分为创新训练、创业训练、创业实践三类（一般为创新训练项目），级别一般分国家级、省级、校级、院级，基本流程为“申报—立项—中期检查—结题验收”，周期通常1年。

总体来讲大创是一个门槛低、较为简单的完整项目，可以锻炼选题、实践、答辩等能力，可以结合专业课知识、竞赛成果、科研项目进行选题。

ps：华科省级项目较多，申报建议选择较高级别，如果不满足要求会顺序降级，避免申报等级较低。每人每年仅能主持一项大创。  
参考25年申报通知https://ugs.hust.edu.cn/info/1142/6858.htm，  
中期检查通知https://ugs.hust.edu.cn/info/1142/7155.htm，
