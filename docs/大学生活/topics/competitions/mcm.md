# 美赛 { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

美赛全称“美国大学生数学建模竞赛（MCM/ICM）”。

这类数学建模比赛本质是在限定时间内，由3人一队用数学、编程和写作对一个开放实际问题完成“建模—求解—验证—成文”的全流程，最终提交一篇论文，考察问题抽象、团队协作和表达呈现的能力；主流赛事中，国赛（CUMCM）每年9月举行、3天3夜、中文写作、本科组3题选1，重结果精确与模型可靠，含金量高。美赛（MCM/ICM）每年2月举行、约4天、英文写作、6题选1（MCM偏数理、ICM偏交叉学科），重创新、呈现与可视化；国赛国一约0.5%、国二约2%，美赛O奖约0.2%、F奖约2%、M奖约6%；

备赛阶段可以多参考b站教学视频，提前熟悉模型，比赛过程中科学使用AI能够极大提高效率和质量。华科有企业微信校内数模群，由于二维码不可转发，可以询问导员或相关老师。
