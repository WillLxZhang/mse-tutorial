# FOCUS { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

FOCUS 团队是由机械学院尹周平院士与陶波教授于2010年创立的科创团队，以华中科技大学机械学院、数字制造装备与技术国家重点实验室为支撑平台，带领大学生进行科研创新活动。

</div>

## 团队概况

<div class="article-box" markdown="1">

区别于其他以比赛为导向的本科生双创团队，FOCUS 是一个以项目为导向的科创团队。其团队管理和运营模式更加类似于研究生模式，内部按各个项目分为各小组进行管理。

经典的项目有如陆空两栖爬壁机器人项目、负压吸附机器人项目、智能实体交互项目、扑翼飞行器项目和索驱动机械臂项目等等，主要涉及智能机器人、特种机器人等前沿领域。

团队除了有指导老师、实验室提供的项目之外，也可以自己提出想法申请项目，是一个可以充分发挥自己灵感与才华的地方。  

同时，团队还提供针对相关技术的培训和一些设备上的支持，可以帮助个人更好地进行项目相关的科研活动。  

此外，FOCUS团队还有举办“微智助企业”活动的传统，即在寒暑假期间组织学生前往小微企业进行一段时间的实习。在实习过程中，不仅可以给自己积攒实习经验，还可以深入了解当今企业的相关情况，是一个很好的实践机会。

面向有意愿参加 FOCUS 团队并兼顾自己的比赛加分同学，可以选择FOCUS团队内方向可快速落地、已有成果产出的项目参加； FOCUS 团队各项目组已经多年参与挑战杯“揭榜挂帅”等各类比赛，成员取得了较丰硕的保研加分、专利论文等产出。

总而言之，FOCUS团队适合注重提升自我科研硬实力，热衷攻克项目的学生参与。

</div>

## 加入FOCUS

<div class="article-box" markdown="1">

FOCUS团队的主要加入方式为春招和秋招，其中秋招面向大一大二同学，大三原则上不进行统招；参加春招强烈建议先参加 FOUCS 团队冬令营，一是能通过考题对团队目前的主要方向有所了解，寻找自己喜欢的方向参加；二是在冬令营中获评优秀营员的学生可直通面试。

欢迎大家加入 FOCUS，祝愿所有想加入 FOCUS 团队的朋友们都能在过程中有所收获，充实自我！

</div>
