# FOCUS { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">


FOCUS 团队是由机械学院陶波老师于2010年创立的科创团队。  

## 团队概况

稍微有别于其他以比赛为导向，FOCUS 是一个以项目为导向的科创团队。其团队管理和运营模式更加类似于研究生模式，内部按各个项目分为各小组进行管理。

经典的项目有如陆空两栖爬壁机器人项目、视觉伺服打标项目、智能实体交互项目、扑翼飞行器项目和索驱动机械臂项目等等，主要涉及智能机器人、特种机器人和具身智能等前沿领域。

团队除了有指导老师、实验室提供的项目之外，也可以自己提出想法申请项目，是一个可以充分发挥自己灵感与才华的地方。  
同时，团队还提供针对相关技术的培训和一些设备上的支持，可以帮助个人更好地进行项目相关的科研活动。  
此外，FOCUS团队还有举办“微智助企业”活动的传统，即在寒暑假期间组织学生前往各企业进行一段时间的实习。在实习过程中，不仅可以给自己积攒实习经验，还可以深入了解当今企业的相关情况，是团队给予学生的一个很好的实践机会。总而言之，FOCUS团队适合注重提升自我科研硬实力、攻克项目为主的学生参与。

需要注意，相对其他科创团队而言，FOCUS 比赛打的会相对来说非常少。除了一些大比赛之外，FOCUS不会组织去打一些小比赛，对那些想多打小比赛刷加分的同学来说不是很友好。  
因此，在这里还是要务实地和想参加 FOCUS 团队，同时也想兼顾自己的比赛加分的同学说清楚，如果真的觉得比赛加分更加重要，其实更推荐去参加其他以比赛为导向的科创团队。如果加入 FOCUS，可以选择FOCUS团队内资源倾斜多、有成果产出、偏原创的项目参加，因为这种项目相对于团队内部其他偏应用的项目，更好参加如挑战杯、双创赛这种A类赛事且也有一定的竞争力，比较好拿到较好的名次（更多的加分）；否则如果同时想要兼顾团队和加分的话，就只能自己关注一些其他的小比赛参加刷分了。

## 加入FOCUS

FOCUS团队的主要加入方式为春招和秋招，其中秋招面向大一大二同学，大三一般不招（特招除外）；参加春招强烈建议先参加 FOUCS 团队冬令营，一是能通过考题对团队目前的主要方向有所了解，寻找自己喜欢的方向参加，二是在冬令营中获评优秀营员的学生在春招当中有相当大的优势，因此强烈推荐。

欢迎大家加入 FOCUS，祝愿所有想加入 FOCUS 团队的朋友们都能在过程中有所收获，充实自我！
