# 蓝桥杯 { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)

<div class="article-box" markdown="1">

蓝桥杯全国大学生软件和信息技术大赛是一项极具学习与成长价值的全国性大学生学科竞赛。蓝桥杯设立省赛与国赛，分为好几个赛项。适合我们机械学院参加的是软件赛中的 **C++ **以及**Python**。这个比赛是个人上机的形式，比赛时间为4h。

## 题型

历届试卷里常见两类题。

**结果填空题**只交最后的答案，可以手算，也可以在电脑上写个小程序帮你算，但通常不好进行手算。

**程序设计题**要根据题目要求手敲代码，然后进行提交。题目通常会给出样例输入和输出，选手可以用来初步评判自己代码的正确性。但样例的正确不代表本题得分，评测系统会换几组输入，看你的程序能不能在规定时间内给出正确输出。对几组就获得相应的分数

## 接触过一点编程，怎么备赛？


1. **仔细品读数据结构与算法：** 无论是C++还是Python，题目的底层逻辑和算法都是一样的，只是实现的形式不同，因此想要独立做出比赛题目需要至少掌握一些基础的算法，可以选择阅读数据或者在网上寻找资料。课内学的C++知识是远远不够的。
2. **注重实操，切忌纸上谈兵：**编程的书籍和线上课程经常会给人一种看完就会了的错觉，但实际做题目的时候就会发现差之甚远。我们作为机械学院的同学，相比科班出身的计算机同学，想要在比赛中同等竞技甚至胜出就一定要弥补代码能力的差距。
3. **用好AI：** 现在ai大模型的能力有目共睹，基本可以handle所有的比赛题目。在备赛时一定不要偷懒，让ai帮自己完成，这样会形成思维惰性。但是一定要学会借助ai教学剖析自己不会的算法，解答困惑以及优化代码，让学习效率获得显著提升。
