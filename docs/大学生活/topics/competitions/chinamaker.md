# ChinaMaker { .section-page-title }

> [竞赛与团队](../../competitions-and-teams.md)



## 团队概况

<div class="article-box" markdown="1">


ChinaMaker 是华科机械学院的本科生创新团队，由[黄永安教授](https://mse.hust.edu.cn/info/1142/1329.htm)创立，依托学院的柔性电子制造团队开展科研实践。2021 年，ChinaMaker 入选全校示范性学生创新团队。团队现由本院博士生夏天实际带领。

“**柔性电子**”听起来有点抽象，大家不妨想象一张贴在小臂上的电子贴片。握拳、伸指的时候，皮肤表面会跟着动。要想让贴片既能贴合皮肤，又能稳定地测到肌肉活动产生的微弱电信号，就要同时考虑它用什么材料、做成什么结构、电极放在哪里，以及采到的信号怎么处理。这也是机械、材料、控制等学科交叉的前沿领域。

</div>

## 研究方向

<div class="article-box" markdown="1">


团队中有多位机械学院的导师，研究方向为柔性电子领域的不同细分方向，各有侧重（材料硬件、软件、ai算法），例如飞机智能蒙皮、机器人电子皮肤、柔性显示等等。研究方向比较**适合先电专业的同学们**，会跟大三的专业课有些重叠。关于导师组成和各自的具体研究方向，这里不方便直接列出，同学们可以关注招新时发布的通告以及导师个人主页。

</div>

## 节奏与强度

<div class="article-box" markdown="1">


团队较为庞大，师资力量雄厚，导师们手上有科研项目也有比赛（挑战杯等）。但整体感觉每个老师都更关注自己的课题组研究方向，没有什么团队的运营，平时不会有学习类或生活类的任何活动，也完全没有任何团队的情怀。开会频率不高且多为画饼。有些老师会提供一些机会，如果自己很主动，有明确感兴趣的研究方向以及强烈的科研欲望，这里一定能提供资源的支持。反之，如果不知道自己喜欢什么方向，也不会主动联系导师，那就很可能会一直挂个名字，学不到东西。

</div>

## 怎么加入 CM？

<div class="article-box" markdown="1">


每年 ChinaMaker 都会发布招新公告。届时的海报会同时列出招新群和招新宣讲会的信息，以及一些团队研究方向。想了解报名方式的同学，可以先关注启明学院的通知资讯，导员一般也会在官方群里发布。[2026 年招新暨冬令营通知（往届参考）](https://qiming.hust.edu.cn/info/1422/4072.htm)

报名后团队会组织统一的面试，由团队导师的研究生师兄师姐主持，通过后便可加入团队。加入团队后会有导师研究方向的宣讲会，届时也会完成学生与导师的双选。

</div>
