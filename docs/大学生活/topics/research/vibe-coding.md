## 一、什么是 Vibe Coding？

** Vibe Coding 是一种以自然语言驱动的软件开发方式。**

我们不再和古早猿类一样需要手敲每一行代码，而是可以尝试通过使用豆包语言输入法等工具，直接用嘴吐出的自然语言描述需求，AI吃了Token钱就会心甘情愿把活干掉。

诚然，截止2026年年底这个时间点，Astra这样的模型已经能解决大部分本科学生遇到的任何工程问题。但并不意味着一句：把XX干掉AI就能帮你写完。本教程旨在提供一条自己认为的AI相关知识的学习途径，教你如何更好VibeCoding，哎图个氛围图个爽嘛。

工程量不大时，建议每一个初学者都自己看一看Ai出的代码，同时保留人类对需求、架构、正确性和最终结果的控制权。Vibe Coding 降低的是代码编写基础的门槛，而非软件工程的复杂度。

AI 可以代替大量代码编写劳动，但不能替代开发者对问题本身的理解与判断。

## 二、理解 Model、Agent 与 Harness

如果你要和朋友吹牛逼，请不要满嘴Codex薄肌大水沙县小吃了，你需要一些专业术语...

### 2.1 Model：模型

LLM Model 主要负责根据输入的上下文生成输出，例如文本、代码、工具调用请求等。模型的参数量/训练方式等等直接决定其生成性能。

常见模型族包括：

- GPT/Claude/Grok/Gemini/Muse/Copilot（科学上网）

- Deepseek/Kimi/GLM/Mimo/MiniMax/Qwen


在网页端，你就大都可以和这些模型进行对话；在更好的Agent和Harness架构下，模型才得以发挥其完整性能。

### 2.2 Agent：智能体

Agent 是一种能够围绕目标进行多步骤决策、调用工具并利用反馈继续执行任务的系统。

例如用户要求：「帮我把Python程序作业写掉，并确保所有测试通过。」

Agent 可能执行如下过程：

1. 查看项目结构

2. 阅读项目依赖与现有代码。

3. 设计接口。

4. 创建或修改 Python 文件。

5. 执行单元测试。

6. 读取报错。

7. 修复错误。

8. 再次执行测试。

9. 汇报结果。


模型是其中的决策核心，Agent 则体现为完整的任务执行机制。

### 2.3 Harness：智能体运行框架

Harness 是围绕模型构建的执行、协调与约束系统。

它负责让模型能够在真实环境中稳定完成任务。

典型 Harness 可能包含：

- **Tool**：文件操作、终端执行、搜索、浏览器等工具接口

- **Context Management**：上下文组织、压缩、检索与截断

- **Execution Loop**：模型调用、工具执行和反馈循环

- **State Management**：任务进度、会话状态和持久化数据

- **Sandbox**：隔离执行环境

- **Permissions**：工具访问与操作权限

- **Error Recovery**：失败重试及异常恢复

- **Observability**：日志、运行轨迹、Token 消耗和性能监控


人机总结：**Model 是决策引擎，Agent 是具备目标导向行为的系统，Harness 则是使这种行为能够可靠运行的基础框架。**

可以将三者理解为：

|概念|核心职责|示例|
|---|---|---|
|Model|理解、推理、生成|GPT/Claude/Qwen|
|Agent|规划、行动、观察、迭代|Coding Agent、Research Agent|
|Harness|工具执行、上下文、权限、环境、状态|Codex/OpenClaw/Hermes|

Codex、Claude Code 等 AI Coding 产品，通常不是单纯的模型接口，而是结合了模型、工具和执行框架的完整系统。

## 三、现代 AI 知识与技术方向

现在 AI 领域每天都有一堆新概念，什么 LLM、VLM、VLA、WAM，听起来一个比一个唬人。主要还是为了骗骗投资人啊，我们广大学生别被骗了。也没必要把每个东西都学一遍，至少先知道大家在研究什么，别一提 AI 就只想到豆包和 DeepSeek。

下面简单介绍几个主要方向和常见术语。这里只负责扫盲，具体原理和教程会在后面附链接。

### 3.1 基础模型与神经网络

- **MLP（多层感知机）**：最基础的神经网络之一，本质上是一堆矩阵运算加非线性变换，很多复杂模型里面依然有它。

- **CNN（卷积神经网络）**：擅长从图片里提取局部特征，曾经是计算机视觉领域的绝对主力。

- **Transformer**：现代大语言模型的核心架构之一，通过 Attention 机制让模型学会利用上下文信息。

- **Attention（注意力机制）**：让模型在处理信息时判断哪些部分更值得关注，而不是一视同仁。

- **LLM（大语言模型）**：GPT、Claude、DeepSeek 等背后的技术，简单理解就是通过海量数据训练出来的语言理解与生成模型。

- **Token**：AI 眼里的文字基本单位，也是各大模型厂商收钱的重要计量单位。

- **Context Window（上下文窗口）**：模型一次能看到的信息总量，窗口再大也不代表 AI 永远不会忘事。

- **KV Cache**：把已经算过的注意力相关数据缓存下来，避免模型生成每个字时都从头计算。

- **Context Engineering（上下文工程）**：研究怎么把真正有用的信息塞给模型，而不是把几十万字一股脑丢进去祈祷。

- **Pretraining / Post-training（预训练/后训练）**：前者让模型学会大量知识和模式，后者进一步教它怎么按要求回答问题、推理和干活。

- **Fine-tuning（微调）**：在已有模型基础上继续训练，让它更适合某个领域或任务。


### 3.2 AI Infra：人工智能基础设施

简单理解就是研究怎么让 AI 跑得更快、更便宜、更稳定，毕竟再聪明的模型也得有显卡给它算。

- **GPU**：AI 时代最重要的计算硬件之一，特别擅长大规模并行运算。

- **CUDA**：NVIDIA 的 GPU 并行计算平台，属于老黄护城河的重要组成部分。

- **PyTorch**：目前非常主流的深度学习框架，训练神经网络经常离不开它。

- **Triton**：用来编写高性能 GPU 计算程序的工具。

- **TensorRT**：NVIDIA 的推理优化工具，主要负责让训练好的模型在部署时跑得更高效。

- **vLLM**：高性能大语言模型推理框架，适合把模型部署成供大量用户调用的服务。

- **Quantization（量化）**：用更低精度的数字表示模型参数或计算结果，以节省显存和计算资源。

- **Distributed Training（分布式训练）**：一张显卡装不下、算不动，那就让很多张显卡一起干活。


### 3.3 Agent 与强化学习

如果说 LLM 主要解决「怎么生成回答」，Agent 更关心「怎么完成任务」。

- **RL（强化学习）**：让模型通过与环境交互、获得奖励来学习策略，有点像训练小动物。

- **PPO**：经典强化学习算法，在机器人控制和语言模型后训练中都有应用。

- **GRPO**：一种强化学习策略优化方法，在部分推理模型训练中比较常见。

- **Agentic RL**：让 Agent 通过强化学习掌握多步骤决策和工具使用，不只是会聊天，还要学会把事情办成。

- **Tool Calling（工具调用）**：让 AI 能调用搜索、终端、文件系统等外部工具，终于不只能靠一张嘴了。俗话说人和猴子的区别就是前者会使用工具。

- **MCP（Model Context Protocol）**：连接 AI 应用与外部工具、数据的标准协议，可以理解为给 Agent 配一套通用接口。

- **RAG（检索增强生成）**：先从外部知识库查资料，再让模型结合资料回答，减少单纯靠模型记忆瞎编的情况。

- **Memory（记忆）**：把重要信息保存在当前上下文之外，让 Agent 在后续任务中还能利用。


### 3.4 多模态与具身智能

语言模型会说话还不够，人类能看、能听、能动，AI 自然也想把这些能力补上。

- **Multimodal AI（多模态 AI）**：让模型同时处理文字、图片、视频、声音等不同形式的信息。

- **VLM（视觉语言模型）**：让 AI 看懂图片并回答问题，比如拍张题目直接问它怎么做。

- **MLLM（多模态大语言模型）**：以大语言模型为核心，进一步融合图像、音频、视频等信息。

- **VLA（视觉语言动作模型）**：把看到的画面、听到的指令转换成机器人动作，让 AI 从动嘴发展到动手。

- **World Model（世界模型）**：让 AI 学习环境如何变化，尝试预测「如果我这么做，接下来会发生什么」。

- **WAM（World Action Model）**：部分研究中用于描述联合建模世界与动作的模型，具体定义需要看对应论文。

- **Sim2Real（仿真到现实）**：先在模拟器里训练机器人，再想办法让学到的技能在真实机器人上也能用。


### 3.5 Computer Vision 与 3D Vision

计算机视觉研究怎么让机器理解图像和三维世界，算是 AI 领域历史比较悠久的方向。

- **CV（计算机视觉）**：让计算机从图片和视频中识别、理解信息。

- **Object Detection（目标检测）**：找到图片里的目标，并用框标出来，比如经典的 YOLO。

- **Segmentation（图像分割）**：不满足于画个框，还要判断哪些像素属于哪个物体，比如 SAM。

- **ViT（Vision Transformer）**：把 Transformer 用到视觉任务上的一类模型架构。

- **3D Vision（三维视觉）**：从图像、深度等信息中理解或恢复三维空间结构。

- **Point Cloud（点云）**：用一堆三维坐标点表示物体或场景的几何形状。

- **SLAM（同步定位与建图）**：机器人一边判断自己在哪里，一边绘制周围环境的地图。

- **NeRF**：用神经网络表示三维场景，可以从新的视角渲染出图像。

- **3DGS（三维高斯泼溅）**：用大量三维高斯基元表示场景，实现高效的新视角渲染。

- **6D Pose Estimation（六维位姿估计）**：判断物体在三维空间中的位置和朝向。

- **3D Generation（三维生成）**：根据文字、图片等条件生成三维模型或场景，建模师看了可能会有点紧张。


以上只是一张非常粗略的 AI 领域地图，很多方向实际上有大量交叉。

**你不需要把这些东西全部学会，至少下次看到某个缩写时，知道它大概在解决什么问题，就已经达到目的了。**

## 四、如何 Vibe Coding？

说完 AI 的基本概念，终于进入正题。

**Vibe Coding 不需要你是计算机大神，但最好也别对编程一窍不通。**

接下来建议从这几个方面开始尝试

### 4.1 至少看得懂一点代码

不需要手搓什么高深算法，但 Python 的变量、循环、函数、类这些基本东西最好认识，Linux 命令行和 Git 也建议了解一下。

至少 AI 改炸了项目，你得知道去哪里找问题，而不是只能再问另一个 AI。

### 4.2 最重要的是抽象能力

比起自己写代码，更重要的是能把一个模糊的想法拆解成清晰的需求。

比如「帮我做个目标识别系统」就很抽象；

换成「读取摄像头画面，用 YOLO 检测行人，在视频中绘制检测框并显示置信度」，AI 就容易理解多了。

**你可以不会写具体实现，但至少应该知道输入是什么、输出是什么、整个程序大致怎么工作。**

学习AI相关知识，本人的方法是开一个Markdown手敲必要的抽象层理解，而不是什么都AI生成。

推荐使用Obisdian等Markdown编辑器或者插件，MD是比Word伟大一百倍的格式。

### 4.3 对专业问题要有基本理解

如果只是写个网页、爬个数据，问题倒不大；如果要用 AI 做算法或者科研，最好先理解基本原理。

否则 AI 写出来一套能跑的代码，你甚至不知道它到底实现了什么，更别说判断结果对不对了。

### 4.4 必须学会使用 Coding Agent

建议从 Codex、Claude Code、Cursor 这类工具开始，而不是永远停留在网页聊天框里让 AI 输出代码，然后自己复制粘贴。

真正的 Coding Agent 可以直接阅读文件、修改项目、运行程序、检查报错并继续修复。

不过工具权限也要看清楚，涉及删除文件、执行陌生命令等操作时别无脑放行。

### 4.5 别让 AI 一上来就乱写

对于已有项目，可以先让 Agent 阅读代码并介绍项目结构。

任务比较复杂时，让它先给出计划，确认方案没问题再执行。

简单任务没必要搞这么多流程，复杂任务则最好拆成几个可以验证的小步骤。

### 4.6 一定要学会测试和 Git

AI 说「任务完成」不代表程序真的正确，自己至少运行一下看看效果。

建议使用 Git 记录代码版本，重要修改前后检查 Diff，功能正常就及时 Commit。

这样至少在 Agent 把项目改炸以后，你还有机会恢复现场。

### 4.7 Prompt 没必要写成八股文

网上那些要求 AI 扮演「拥有二十年经验的世界顶级架构师」的神秘 Prompt，没必要过度迷信。

对于现代 Coding Agent，把**需求、项目背景、限制条件和验收标准**讲清楚，通常比堆砌角色设定更有价值。自己多尝试不同的Prompt，对比实现能力更重要。

### 说了这么多，最重要的一定是去用，建议看完一点教程大家先去往Deepseek里充个30块钱，然后尝试自己的第一次Vibe，一切问题和经验都是在实践中发现总结出来的。

## 五、个人瞎总结

写这篇教程不是为了让大家背一大堆 AI 缩写，更不是要求所有人转行学人工智能。

主要还是希望大家别把 AI 的使用方式局限在豆包、DeepSeek 的聊天框里，问两个问题、复制两段代码就结束了。

现在的 AI 已经能够实际参与相当多的软件开发工作，值得花一点时间了解它的能力和使用方式。

AI时代，我们不需要大量的力工劳动和记忆性学习了，很喜欢一些博主的暴论，男娘将会掌握下一个时代的主动权，因为他们又有男性的执行力又有女性的审美。

**未来不一定每个人都需要成为程序员，但知道如何借助 AI 把自己的想法变成能够运行的东西，绝对是一项值得掌握的能力。**

以上，祝大家 Vibe Coding 愉快，少调环境，少烧 Token。
