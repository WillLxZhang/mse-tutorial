# 推免流程 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

推免主要包含本院资格确认、申请与考核、推免系统确认三个环节。具体时间和材料要求每年可能调整，请务必以当年学校、学院和接收单位的通知为准。（23级应该是最后一届9月填写推免系统的年级了）

</div>

<div class="article-box" markdown="1">

1. **大致确定自己推免资格**：按学院往年保研范围，大致确定自己是否拥有保研资格。如果有，就按保研流程准备；如果没有，就尽早准备考研、工作；如果在边缘并且想保研，需要投入更多的精力在加权上。这一步最好在大二就完成，大三大家分都高，拉不开区分度、很难追的。

</div>

## 保本校

<div class="article-box" markdown="1">

2. **确定培养类型与方向**：了解意向学院接收推免生的往届情况，学硕/专硕/直博类型和导师要求；套磁[套磁](contacting-supervisors.md)。
3. **完成校内接收程序**：按接收学院通知报名并参加考核，确认拟接收结果。取得本院推免资格和接收学院拟接收资格，两项都需要完成。
4. **在推免服务系统确认**：系统开放后填报本校对应学院和专业，及时确认复试通知与待录取通知。最终录取以全国推免服务系统中的确认结果为准。

</div>

## 保外校

<div class="article-box" markdown="1">

1. **准备并投递材料**：关注目标院校的夏令营、预推免和正式推免通知，按要求提交成绩单、排名证明、简历、个人陈述等[文书](documents.md)。导师沟通要求因院系和项目而异。
2. **参加目标院校考核**：完成材料审核、笔试、面试或导师交流，获得拟接收或预录取意向。校方意向仍需通过全国推免服务系统完成正式确认。
3. **确认本院推免资格**：按机械学院当年通知完成申请、综合评价与名单公示。尚未正式确认资格时，可根据预计排名提前准备申请。
4. **在推免服务系统确认**：填报目标院校和专业，及时确认复试通知。通过考核后，在规定时间内接受一份待录取通知；接受后即完成当年推免录取确认。

</div>

通知提交申请和证明材料，参加学院组织的综合评价，关注拟推荐名单及公示结果。
