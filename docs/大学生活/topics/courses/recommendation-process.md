# 推免流程 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">
推免，即推荐免试，也就是我们常说的“保研”。

推免主要包含本院资格确认、申请与考核、推免系统确认三个环节。具体时间和材料要求每年可能调整，请务必以当年学校、学院和接收单位的通知为准。（23级应该是最后一届9月填写推免系统的年级了，以后不知道会变成什么样子）

</div>

<div class="article-box" markdown="1">

不管保本校还是保外校，推免的大致环节均如下，不存在保内保外名额分开之说：

1. **大致确定自己推免资格**：按学院往年保研范围，大致确定自己是否拥有保研资格。
     - 如果有，就按保研流程准备；
     - 如果没有，就尽早准备考研、工作；
     - 如果在边缘并且想保研，需要投入更多的精力在加权上。这一步最好在大二就完成，大三大家分都高，加权成绩在这一年拉不开区分度，很难追的。
2. **找老师：**[套磁](contacting-supervisors.md)、询问是否有名额并取得联系。经过面试、考核，以及夏令营、预推免等环节获得 offer。
3. **公布保研名额：**在大三成绩出完之后，学院会根据排名公布保研名额，这时候可以确定自己是否拥有保研名额。**注意：保研指标一般分为普通指标（硕、博选择取决于你和联系到老师的共同选择）和工程硕博指标（特殊），见[硕博之选](master-or-phd.md)**
4. **填写系统：**结合自己联系老师的情况，填写保研系统（教育部官方，和高考志愿类似，有三个志愿）。
</div>

## 不同之处

### 保本校

<div class="article-box" markdown="1">


保本校的确定性相对较高，通常只要拿到本校推免资格，且满足基本绩点要求，以机械学院为例，基本无需参加夏令营，预推免也是走一个过场。

导师对本校学生更了解，大都更喜欢招自己学院的学生。

</div>

## 保外校

<div class="article-box" markdown="1">
保外校一般面向外校的每个学院申请，会与全国的同级学生竞争。随着保研流程的提前，以后的这些流程会有所不同，这里复现一下往年的流程大家简单了解即可：

>如果以后的推免流程变化不大，我们会做夏令营、预推免的汇总，提供更详细的内容

### 夏令营
时间：常常在6-8月，提前一段时间报名，需要投递[文书](documents.md)进行背景筛选。注意，导师沟通要求因院系和项目而异，但前期套磁等方面的流程是通用的。

地点：一般会去目标院校的线下进行，也有过线上。

流程：通常含有面试、笔试、机试等环节，考核学生学业、科研方面的硬实力和临场应变等综合能力。

效力：一般结束后会发放优秀营员。其效力因学院而异：有些学院优营意味着铁 offer，有些则是无效力。这个具体情况需要结合具体学院往年的情况而确定。

注意：
- 很多院校每人只能填1个志愿，比如 SJTU，有统一的系统，并且大部分夏令营时间重合，基本一所学校只能报一个夏令营。
- 有些学院区分强弱com。com = committee，即学院的招生委员会。强弱com的区别在于：招生录取的决定权在学院手里还是在导师手里：
  -  强com：学院招生委员会掌握录取决定权。流程是学院统一筛选入营、统一笔试面试，按绩点、排名等硬性指标打分排序。导师话语权较小，即使提前联系了导师，没过学院考核也很难被捞进来。

  - 弱com：导师/课题组在招生中有较大自主权，名额可能直接下达到导师个人。导师点头基本等于半只脚上岸，学院后续流程多为走个过场。

  - 混合com：部分院系介于两者之间，比如博士是弱com，硕士强com。


### 预推免
时间：8-9月各校陆续开放，最晚会到比填写保研系统4-5天前。

性质：夏令营没拿到满意offer的下一个机会（其实这个才是最官方的，夏令营其实更像是学校自己办的提前批）。不少院系压根不办夏令营，名额全放在预推免，所以对大部分朋友来说，预推免才是主战场。

流程：面试、笔试、机试等环节和夏令营差不多。节奏比夏令营更快。

效力：一般结束后会发放铁 offer，基本比较确定了。

注意：时间紧、节奏快，导师要提前套磁。


### 正式推免/九推

在规定的时间，于全国推免服务系统填报自己取得offer的目标院校和专业，如果院系要你，就会给你发放复试通知，然后你确认 -> 这份通知就变成了待录取通知，你只能接受一份待录取通知。接受后即完成当年推免录取，你的去向就固定了。

九推：本质捡漏——在系统中填写，需要与老师联系，前面有人放弃offer会空出名额，这个名额就归你了。

</div>
