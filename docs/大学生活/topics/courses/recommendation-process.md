# 推免流程 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">
推免，即推荐免试，也就是我们常说的“保研”。

推免主要包含本院资格确认、申请与考核、推免系统确认三个环节。具体时间和材料要求每年可能调整，请务必以当年学校、学院和接收单位的通知为准。（23级应该是最后一届9月填写推免系统的年级了，以后不知道会变成什么样子）

</div>

<div class="article-box" markdown="1">

不管保本校还是保外校，推免的大致环节均如下：

1. **大致确定自己推免资格**：按学院往年保研范围，大致确定自己是否拥有保研资格。
  - 如果有，就按保研流程准备；
  - 如果没有，就尽早准备考研、工作；
  - 如果在边缘并且想保研，需要投入更多的精力在加权上。这一步最好在大二就完成，大三大家分都高，加权成绩在这一年拉不开区分度，很难追的。
2. **找老师：**套磁、询问是否有名额并取得联系。经过面试、考核，以及夏令营、预推免等环节获得 offer。
3. **公布保研名额：**在大三成绩出完之后，学院会根据排名公布保研名额，这时候可以确定自己是否拥有保研名额。**注意：保研指标一般分为普通指标（硕、博选择取决于你和联系到老师的共同选择）和工程硕博指标（特殊），见docs\大学生活\topics\courses\master-or-phd.md**
4. **填写系统：**结合自己联系老师的情况，填写保研系统（教育部官方，和高考志愿类似，有三个志愿）。
</div>

## 不同之处
### 保本校

<div class="article-box" markdown="1">

保本校的确定性相对较高，通常只要拿到本校推免资格，且满足基本绩点要求，以机械学院为例，基本无需参加夏令营，预推免也是走一个过场。

导师对本校学生更了解，大都更喜欢招自己学院的学生。

</div>

## 保外校

<div class="article-box" markdown="1">
保外校一般面向学院申请，会与全国的同级学生竞争，

1. **准备并投递材料**：关注目标院校的夏令营、预推免和正式推免通知，按要求提交成绩单、排名证明、简历、个人陈述等[文书](documents.md)。注意，导师沟通要求因院系和项目而异，但前期套磁等方面的流程是通用的。
2. **参加目标院校考核**：完成材料审核、笔试、面试或导师交流，获得拟接收或预录取意向。校方意向仍需通过全国推免服务系统完成正式确认。
3. **确认本院推免资格**：按机械学院当年通知完成申请、综合评价与名单公示。尚未正式确认资格时，可根据预计排名提前准备申请。
4. **在推免服务系统确认**：填报目标院校和专业，及时确认复试通知。通过考核后，在规定时间内接受一份待录取通知；接受后即完成当年推免录取确认。

</div>
