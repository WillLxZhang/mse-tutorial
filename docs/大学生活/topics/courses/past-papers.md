# 历年题 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

华科的历年题一般有 4 种渠道：

- 老师发的（情况较少），如果有一定要认真做
- 韵苑一栋文印店买的（不知道搬了没搬），会有一些陈年老题（实在没得做可以买点）
- 坊间流传（这个比较权威，具体请咨询前辈）
- 以前有一个资料叫“学解”，上面有一些历年题，不过由于黑心商家和答案真实性等因素已经停止售卖

历年题是仅次于书本知识、课后作业以外最宝贵的考试准备资源，一定要想办法多弄到一些
