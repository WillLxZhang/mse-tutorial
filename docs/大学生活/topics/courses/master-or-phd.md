# 硕博之选 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

硕士与博士在培养周期、研究投入和未来规划等方面存在很大的差异，同时内地与出国境的情况有所不同。

内地：

1. 硕士：多为 3 年制
    - 学硕：侧重学术（发文章），也会有一定的写本子（项目申报书）要求，毕业一般存在一定的要求（如发一篇文章）
    - 专硕：侧重项目，工作多为横向、纵向，毕业一般无要求
2. 博士：
    - 直博：从本科毕业直接申请博士，对个人规划认知与科研能力有一定的要求，同时由于本身难度较高，申请难度相应硕士较低。内地正常来讲为5年毕业
    - 普博：硕士毕业后读的博士，正常来讲为4年毕业
    - 硕博连读：部分课题组的硕士出于个人发展考虑，会在读硕士的1-2年左右决定转博士，这种情况下其学龄也直接按博士算，一般为硕+博=6~7年，
    - 工程硕博：待补充，各个学校情况不太一样

大家尽量在申请季之前明确硕博之选，结合自己的科研兴趣、职业发展目标、风险承受能力和具体课题组情况综合判断。

</div>
