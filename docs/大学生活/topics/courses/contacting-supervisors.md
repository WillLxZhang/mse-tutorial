# 套磁 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

“套磁”指申请者在正式录取前主动联系导师，介绍自己的背景、研究兴趣和申请计划，并询问招生名额、方向匹配或进一步交流的可能性。主要通过邮件进行联系

联系前可以先阅读意向导师的主页、近期论文和招生说明，确认研究方向与自身经历或意向存在具体交集。邮件正文宜简短，说明身份、申请年级、相关经历和联系原因。简历、成绩单等材料按自己的理解或对方要求（如有）附上。

对不同导师分别微调自己的文书和邮件正文，适应与其方向相关的内容，比批量发送同一封邮件更有效。

对方未回复时，可以间隔一段时间礼貌跟进一次，如仍无回复可以再继续联系其他合适的导师。

</div>
