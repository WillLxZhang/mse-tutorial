# 文书 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

“文书”是升学申请中用于介绍个人背景、经历与申请动机的材料，常见形式包括个人简历（CV）、个人陈述（PS）、目的陈述（SOP）、研究计划和PPT等内容。

需要主动联系导师时，可参考[套磁](contacting-supervisors.md)。

如果感觉无从下手，不知道怎么准备自己的简历，可以通过经验贴中的联系方式联系前辈获取参考。

</div>

> by Will Z
