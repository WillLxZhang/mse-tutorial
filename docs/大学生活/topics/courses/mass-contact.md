# 海投 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

“海投”指在对个人定位有初步认知，并且明确调研过不同方向、不同老师的情况下，较广泛地联系导师或申请项目。

比如：明确自己对机器人 / 集成感兴趣，对两个方向都有一定的积累和理解，筛选目标院校的大量老师后，每天发一定数量的邮件，等待某院系的老师回复过后决定入面/拒绝，然后再给该院系老师发下一封，如此滚动，保证每个院系只有一封套磁信在投的情况下，尽可能多地联系老师，有可能大大增加自己的升学机会。
