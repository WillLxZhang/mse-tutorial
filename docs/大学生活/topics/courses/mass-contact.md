# 海投 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

“海投”指在对个人定位有明确认知，并且深入调研过不同方向、不同老师的情况下，较广泛地联系导师或申请项目。

比如：
- M 同学明确自己对机器人 / 集成感兴趣，对两个方向都有一定的积累和理解。  
- 在筛选了目标院校的大量老师后，M 同学每天会发一定数量的邮件：给 A 校 A 院，B 校 A 院，B 校 B 院，A 校 B 院的四位老师发送四封套磁信。（尽量不要给同一学院同时发送多封套磁信，如果那几位老师互相认识，会降低印象分）
- 此后 M 同学需要等待某院系的老师回复，老师会决定 M 同学进入面试/拒绝，如果进入面试，则认真准备，如果拒绝，可以着手准备给该院系老师发下一封。
- 如此滚动，尽可能多地联系老师，有可能大大增加自己的升学机会。

</div>
