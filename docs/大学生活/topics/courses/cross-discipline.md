# 跨保 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

“跨保”适用于申请的专业、院系或研究方向与本科专业存在一定跨度的情形，如本科为机械专业，保研至 CS / AI / 自动化等专业。其信息差更大，难度也相应较高。

不过本科期间，工科大类的各个专业相差不大，只要不是跨行业跨大类，通过适当的准备足够抹平本科期间的差别，个人感受来讲和保本专业区别不大。作为研究生或者准研究生，大家都有从头学习的资本。

</div>
