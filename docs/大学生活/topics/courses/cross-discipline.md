# 跨保 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

“跨保”适用于申请的专业、院系或研究方向与本科专业存在一定跨度，其信息差更大，难度也相应较高。不过本科期间工科专业相差不大，只要不是跨行业跨大类，通过适当的准备可以抹平本科期间的差别，个人感受区别不大
