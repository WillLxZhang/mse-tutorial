# 加权排名与综合排名 { .section-page-title }

> [课程与学业](../../courses-and-study.md)

<div class="article-box" markdown="1">

加权成绩与排名是裸分排名，综合排名是加了竞赛等因素之后的排名。

## 加权成绩

这学期你修了 A / B / C 三门课，A 有 4 学分，B 有 5 学分，C 有 2 学分。你分别考了 90 / 88 / 93，恭喜你，你这学期的加权成绩为：

$$
\begin{aligned}
\bar S &= \frac{4(90) + 5(88) + 2(93)}{4 + 5 + 2}\\
&= \frac{986}{11} \approx 89.64
\end{aligned}
$$

加权成绩是本科阶段最重要的资产，大家一定一定要重视。

前六学期的奖学金等评选都是根据加权成绩的排名进行

## 综合排名

以机械学院为例，保研名额的确定以综合排名来进行，体现了全方面发展的导向。

往届的加分规则可供参考：
分为 A / B / C 三类项目，A 类包含挑战杯等权威赛事，B 类包含成图赛、机创赛等含金量较高的赛事，C 类包含前述赛事的省奖、其他赛事还有三好学生称号等条目的加分。加分上限为 15 分，如 3 个 B 类国一为 3 × 5 = 15 分，可以加满。然后乘以 0.3 加到加权成绩上，是为综合成绩，进行综合排名。

每届的规则都不一样，比如加分规则，乘以0.3的这个系数，请务必以自己大三时收到的通知为准
