# 嵌入式 { .section-page-title }

> [专业方向](../../majors-and-directions.md)



<div class="article-box" markdown="1">

## 总体介绍

嵌入式指的是利用嵌入式开发工具（主要就是嵌入式芯片，包括stm32、esp32等）作为中介，将软件（控制程序、上位机软件）与硬件（电路、开发板、机械结构、传感器等）进行结合，从而使得软件能够控制硬件，硬件能够给软件反馈足够的信息，系统能够达到预期的运行效果。

通俗来说，传统机械工程师做的事情是设计一套系统的物理结构，嵌入式工程师要做的便是驱动这套系统完成各种目标任务。

## 需要的技能

语言基础就是C/C++，这是写代码的立足之本。

数据结构、计算机组成原理，在RTOS开发，理解嵌入式底层原理方面很重要；

电路基础、数电、模电也需要有一定理解，要看得懂原理图，懂得如何接线配引脚等；

然后就是GPIO、PWM、中断、串口、回调、RTOS、甚至FPGA、Linux开发等等概念。

这些概念都是初听拗口，但是多用就会很熟。因此推荐先实际开始做一些项目，在项目中同步学习，需要用到哪些就补充哪些部分的知识库。

## 总结

嵌入式工程师既要懂软件、也得懂硬件，是一个很吃经验与熟练度的方向。归根到底，嵌入式只是一种工具，关键还是在于如何应用，因此还是建议多做项目，多从项目中总结经验，熟能生巧。
