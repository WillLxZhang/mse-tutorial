# 集成 { .section-page-title }

> [专业方向](../../majors-and-directions.md)

<div class="article-box" markdown="1">

机械与集成交叉通常是在制造、工艺、mems（微机电系统）这几个方向，EDA、集成电路设计等方向跨越较大。不同方向发展与就业前景相差角度，建议自行了解。其中机械学院先进电子制造方向会学习半导体物理、电子封装、半导体制作工艺、mems等课程，与集电有所交叉。

</div>
