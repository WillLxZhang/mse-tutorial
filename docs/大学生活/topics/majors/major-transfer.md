# 转专业 { .section-page-title }

> [专业方向](../../majors-and-directions.md)

<div class="article-box" markdown="1">

华科对转专业很宽容，一般存在3次转专业机会：
## 入学转专业考试
入学后会有一个转专业考试，考各个专业的启明班、卓越班等内容。启明班和卓越班的特点主要是：课程难度较大（如数学不学微积分，而是学一元分析学和多元分析学）；小班制（30人左右）；会有自己的特色课程和培养方案。需要大家根据自己得到的信息慎重抉择。

## 大一正式转专业考试
时间：每年12月份初  
内容：分别为笔试和面试，每个院系转入指标有限，以报名时候的通知为准。笔试考试科目为微积分和英语（计算机学院要考编程，其他专业不用）

- 这次转专业是大家的**主战场**，难度相对较低，只要认真备考微积分等内容，基本可以去自己的意向院系。学校的转专业群：576053139，里会有每年转专业考试的笔试面试真题，最重要的就是把过去几年的真题全部做完并且弄懂。英语的题型和高考差不多，，听力最难，吃老本问题不大。

- 笔试通过了之后会进入面试：面试前需要准备个人资料（以前的荣誉证书、简历）。面试时会有自我介绍，面试官会根据简历提问，有可能也会有英语提问。群里也有面试真题，请务必了解自己想转的专业学什么，未来的就业方向是什么。面试的分数一般占比较低，所以最重要的还是备考笔试。

## 大二大类内转专业
这个了解的人较少，信息也不算透明。大致形式为大二下会在专业内提供转专业机会，如机械大类的机械、能源、材料等可以互通，通知见https://ugs.hust.edu.cn/info/1142/6842.htm。
