# 测控技术与仪器 { .section-page-title }

> [专业方向](../../majors-and-directions.md)





## 专业介绍

<div class="article-box" markdown="1">

机械学院的测控专业，是在机械课程的基础上，进一步学习光、电相关课程与实验的专业。

</div>

## 主修课程

<div class="article-box" markdown="1">

大一与大二上学期主要学习机械方向的基础课，包括机械设计理论与方法、工程力学、机械原理、机械设计等，打牢机械结构方面的底子。

从大二开始，课程重心会逐步转向光与电。电学与控制方向主要学习模拟电子技术、数字电路与逻辑设计、信号与线性系统、传感技术与信号电路等课程；光学与仪器方向则会学习工程光学、光电检测技术、精密仪器设计理论与方法、智能视觉检测技术等课程，同时配有大量的实验课。

从课程安排就能看出来，这个专业横跨了机、电、光三个领域。这样什么都学带来的最大特点就是知识面广，但每块内容都只学个皮毛，杂而不精。

</div>

## 学科竞赛与科研方向

<div class="article-box" markdown="1">


要解决课本知识“杂而不精”的问题，最好的办法就是去参加各类机器人比赛或机创赛等学科竞赛，在动手做项目的过程里把学到的东西真正用起来，同时也能为后续保研攒下重要的综测加分。

在比赛团队里，测控专业并不会局限你的定位。不管是机械结构、硬件电路、单片机电控还是视觉算法，完全可以以自己的兴趣为导向，在团队里边学边练。大家除了大一刚入学时的招新，在大一下学期专业分流之后，也可以关注各个比赛团队的春招机会入队。

除了打比赛，也建议大家尽早进实验室接触科研，主要目的是提前探路、确认自己未来的细化方向。目前学院仪器系导师的研究方向，大体可以概括为三类：一是精密光学测量、视觉与无损检测（如微纳表面测量、电磁与超声检测等）；二是智能微系统与微纳传感（如 MEMS 芯片、微纳制造、激光雷达等）；三是医工交叉类的生物医学仪器（如医学光学成像、智能医疗检测设备等）。

找老师不需要等学院统一安排，直接去学院官网的师资队伍页面查看老师介绍，挑感兴趣的方向发邮件自荐即可。大家不用担心自己刚开始什么都不会，老师对本科生并不要求有多高深的理论基础，更看重你的学习态度、动手意愿以及能否踏实投入时间（比如进去先跟着师兄师姐画机械结构、调调电路或写代码跑数据），早点进组试错才能摸清自己到底喜欢哪个方向。

</div>

## 保研与深造去向

<div class="article-box" markdown="1">

测控专业的保研政策、名额构成（包含普通保研与工程硕博专项等）以及保研率，整体上与机械学院其他专业差不多，同样是根据大三时的综合排名（加权成绩 + 竞赛科研等加分）来确定最终名额。

在深造去向上，身处机械学院也是测控的一大优势。保研或考研时如果选择留在本院，去学院其他的细分专业基本不算跨保，阻力很小。除了留在仪器系继续深造，大家如果对机器人、智能制造等方向感兴趣，也完全可以联系学院里的机器人等热门课题组攻读研究生。

每届的具体保研政策与加分细则都会有调整，请务必以自己大三时收到的通知为准。

</div>
