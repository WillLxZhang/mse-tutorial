# 校园生活与资源 { .section-page-title }

本页整理荣誉、学生工作与升学准备中常见的资源和概念。评审条件与推免安排可能调整，请以学校和目标院校当年发布的正式通知为准。

## 特优生 { #special-student }

“本科特优生”是部分经验作者获得的本科阶段综合荣誉。申报通常需要结合成绩、科研竞赛和社会工作等经历准备材料，具体条件和名额以学院当年通知为准。

## 国家奖学金 { #national-scholarship }

国家奖学金用于奖励本科阶段表现突出的学生。经验文章中的“校级三好学生”也统一链接到这里，方便集中了解荣誉评选、材料整理和答辩经验。

## 学习委员 { #study-committee }

学习委员主要承担班级学习信息沟通、课程事务协助等工作。它可以锻炼沟通与组织能力，也需要与课程、竞赛和科研时间协调。

## 个人背景（BG） { #background }

“BG”是经验分享中对个人背景的简称，通常包括成绩排名、科研、竞赛、英语、项目、荣誉和专业匹配度。不同项目关注点不同，整理时应围绕目标方向突出有效信息。

## 申请季 { #application-season }

“申请季”通常涵盖材料准备、联系导师、夏令营、预推免、面试考核和最终确认等环节。不同学校的时间线可能交叉，建议提前整理截止日期与优先级。

## 推免流程 { #recommendation-process }

推免流程包含本校资格确认与外校申请等环节。经验文章可以提供准备思路，正式条件、材料和节点应以学校当年文件为准。

## 海投 { #mass-contact }

“海投”指在明确方向和基本匹配度后，较广泛地联系导师或申请项目。执行时需要记录沟通状态，并根据不同导师和项目调整材料。

## 跨保 { #cross-discipline }

“跨保”指申请与本科专业存在一定跨度的院系或研究方向。准备重点通常包括方向匹配、基础知识、项目证明和对目标领域的理解。

## 硕博之选 { #master-or-phd }

硕士与博士在培养周期、研究投入、导师匹配和未来规划上存在差异。选择前可以结合科研兴趣、职业目标、风险承受能力和具体课题组情况综合判断。
