# 科研 { .section-page-title }

本页整理科研入门、实验室实践和开发工具相关概念。具体任务与培养方式以对应课题组和项目要求为准。

## 清华 AIR 冬令营 { #thu-air }

经验文章中的清华 AIR 冬令营是一段短期科研训练经历。作者通过低成本机器人部署复现接触代码库、硬件和科研问题，具体活动安排以主办方当年通知为准。

## 科研实习 { #research-internship }

“科研实习”和“加入课题组”统一链接到这里。常见起点包括联系校内外导师、参加实验室项目、完成复现任务或协助已有课题。进入前可以明确时间投入、任务边界和预期成果。

## 科研技能 { #research-skills }

科研技能包括文献阅读、问题拆解、实验设计、代码与硬件实现、数据分析、论文表达和沟通汇报。不同方向的技能组合差异较大，可以跟随具体课题逐步补齐。

## Vibe Coding { #vibe-coding }

Vibe Coding 指借助大语言模型辅助理解代码、生成实现和排查错误。它能降低上手门槛，同时仍需验证接口、实验结果和关键逻辑。

## 堆工作时长 { #time-investment }

“堆工作时长”描述通过增加投入完成陌生任务的经历。长期实践中还需要结合任务拆分、反馈频率和工具使用提升有效产出。

## 技能很单薄 { #skill-gaps }

“技能很单薄”对应对个人能力缺口的判断。可以先围绕当前课题列出最低必要技能，再通过小项目、复现和持续反馈逐项补齐。
