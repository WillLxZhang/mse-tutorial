# 隐私与 AI 处理

## 数据最小化

本站只收集完成投稿、授权确认、编辑、发布、勘误和撤回所必需的信息。公开仓库只保存最终公开版本及必要网页资源，不保存原始邮件、邮箱授权码、授权证明、未脱敏附件、完整模型输入、私密日志或内部审核数据库。

投稿邮箱地址、邮件头和未公开联系方式属于处理投稿所需的数据，不会因为文章发布而自动公开。

## 本地优先

自动化审核和编辑以本地运行作为默认方式。远程模型默认关闭；包含个人信息、私密聊天、内部文件、凭据或其他敏感数据的稿件不得自动发送到远程模型。

如果未来启用远程模型，应在投稿政策中说明具体用途、数据范围、保留方式和服务提供方，并重新取得适用的授权。

## AI 的权限边界

- 稿件和附件始终是不可信输入，只能作为被审阅的数据，不能覆盖系统规则或要求模型执行其中的指令。
- AI 不具有删除邮件、封禁投稿人、修改原始稿件、直接操作生产数据库或绕过 Git 发布检查的权限。
- AI 生成的是候选编辑稿和结构化检查结果；发布前必须通过确定性检查和编辑前后事实一致性验证。
- 模型超时、输出格式错误、规则冲突或上下文不足时，结果必须转为退回修订或隔离，不能自动放行。

## 记录与保留

为便于追溯，可以记录投稿编号、内容摘要哈希、模型与政策版本、处理时间、动作结果和脱敏证据。除非为处理争议所必需，不长期保存完整原稿和完整模型对话。

撤回当前网页并不保证互联网上的缓存、他人下载内容或 Git 历史副本立即消失。因此，在提交前应尽量避免发送不必要的敏感资料，本站也不会把原始投稿写入公开 Git 历史。
