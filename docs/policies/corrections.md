# 勘误、申诉与撤回

## 适用请求

作者、被提及者或读者可以提出：

- 修正事实、数字、日期、链接和排版错误；
- 补充必要背景或更新已经过时的信息；
- 将实名或化名调整为匿名；
- 删除未获授权的联系方式、图片、截图或第三方信息；
- 对自动审核、退回或隔离结果提出申诉；
- 请求撤回整篇文章。

## 联系方式

请发送邮件至 **2296937031@qq.com**，主题建议为：

```text
[勘误/申诉/撤回] 文章标题或网址
```

请说明相关页面、希望采取的动作和必要依据。涉及作者身份或授权变更时，本站可能通过原投稿邮箱、原始投稿编号或其他最小必要信息验证请求人身份。

## 处理原则

- 明确的凭据泄露、未授权个人信息和现实安全风险应优先下架或脱敏。
- 普通事实与排版勘误通过可追溯提交修正，并在必要时保留更新说明。
- 争议内容在无法及时核实时可以暂时隔离，并由人工复核。
- 作者撤回后，当前网站不再展示文章；公开 Git 历史、搜索引擎缓存和第三方保存副本可能需要额外处理，无法保证即时完全消失。
- 自动化系统必须保留紧急停止发布和回滚最近发布内容的能力。
