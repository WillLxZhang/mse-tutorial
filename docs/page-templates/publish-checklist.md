# 发布检查清单

## 内容检查

- [ ] 标题清楚。
- [ ] 栏目放置正确。
- [ ] 格式统一。
- [ ] 链接可打开。
- [ ] 图片能显示。
- [ ] 表格在手机端可读。

## 隐私检查

- [ ] 没有学号。
- [ ] 没有身份证号。
- [ ] 没有手机号，除非作者明确同意。
- [ ] 没有未授权邮箱、微信号。
- [ ] 没有未打码截图。
- [ ] 没有未授权简历、成绩单、offer 截图。

## 发布检查

- [ ] 已本地运行 `mkdocs serve` 预览。
- [ ] 已运行 `mkdocs build`。
- [ ] 已在 `mkdocs.yml` 中加入导航入口。
- [ ] 已记录作者授权情况。
- [ ] 已记录发布时间和维护人。
