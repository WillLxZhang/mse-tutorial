# 投稿

本站接收大学生活、课程、科研、竞赛、实习、保研、考研、留学和其他与校园成长有关的一手经验。合理批评和负面经历可以投稿，但请区分个人感受与可验证的事实陈述。

## 投稿前请确认

- [ ] 投稿人是否同意公开发布。
- [ ] 投稿人确认是否匿名。
- [ ] 投稿人确认是否公开联系方式。
- [ ] 稿件中没有不应公开的个人信息。
- [ ] 图片、截图、PDF 等内容已检查隐私信息。
- [ ] 投稿人有权提交正文和附件，并已取得其中第三方信息的必要授权。
- [ ] 投稿人理解稿件可能由网站维护者/本地自动化工具和 AI 辅助检查、排版与润色。
- [ ] 投稿人已经核对院校、时间、成绩、排名、Offer、论文和其他事实性信息。

## 投稿方式

请打包发送至：**2296937031@qq.com**

建议邮件标题：

```text
[投稿] 栏目 - 文章标题 - 公开称谓
```

邮件正文请写明：

```text
1. 希望公开的称谓：实名 / 化名 / 匿名
2. 联系方式是否允许公开：是 / 否；允许公开的具体内容
3. 是否允许 AI 做格式和语言润色：是 / 否
4. 图片、截图和第三方信息是否已获得必要授权：是 / 否 / 不涉及
5. 是否同意本站按照当前投稿政策公开发布：是 / 否
```

请勿发送密码、API Key、私钥、身份证原件或与文章无关的内部资料。投稿邮箱只用于接收和沟通，不代表投稿会被立即公开。

## 稿件格式

支持 Markdown、Word 或纯文本。图片请使用清晰、必要且已经脱敏的版本；不要提交包含无关聊天记录、完整学号、证件号码或他人联系方式的截图。

投稿人可以直接套用：

- [经验文章模板](page-templates/article.md)
- [发布检查清单](page-templates/publish-checklist.md)

## 发布流程

1. 邮箱接收稿件，并按邮件 `Message-ID` 和内容摘要避免重复处理。
2. 确认公开授权、匿名方式、附件权利和联系方式范围。
3. 对正文与附件进行格式、隐私、凭据、安全和内容规则检查。
4. 在不改变事实和观点的前提下生成候选编辑稿，并核对编辑前后的姓名、数字、日期、院校、结果和关键主张。
5. 通过检查的文章以独立 Git 分支和 Pull Request 进入发布流程；检查失败的稿件自动退回补充或隔离，不直接公开。
6. 发布后接受作者和读者提出的勘误、申诉、匿名化与撤回请求。

详细规则见[内容政策](policies/content-policy.md)、[隐私与 AI 处理](policies/privacy-ai.md)和[勘误、申诉与撤回](policies/corrections.md)。
