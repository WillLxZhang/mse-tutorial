# 关于 **HUST MSE Tutorial**

## 项目说明

<div class="article-box" markdown="1">

本项目名为 HUST MSE Tutorial ，译为华科机械入门手册。

在大学生活里，信息差长期存在于课业、科研、竞赛、校园生活和升学等方面中。HUST MSE Tutorial 希望保存来自往届同学的一手经验，让后来者能够看到更多路径，并结合自己的情况做出判断。

本站是由学生发起和维护的经验分享项目，不代表华中科技大学、华中科技大学机械科学与工程学院、任何实验室或教师的官方网站的观点，所有文章只代表作者在特定时间和背景下的个人经历，不构成录取、升学、就业或其他结果的保证。

</div>

## 内容原则（详见[内容政策](policies/content-policy.md)）

<div class="article-box" markdown="1">

- 优先收录真实的一手经历，清楚区分个人感受、事实陈述和推测。
- 允许合理批评和负面经验，不因内容对学校、学院、教师或项目不利而自动拒绝。
- 不冒充官方立场，不发布未获授权的个人信息、凭据、私密材料或针对具体个人的无依据严重指控。
- 尊重作者原意。编辑有权改善结构、格式和表达，但不能擅自改变事实、数字、日期、身份、结果或观点。
- 对不确定和高风险内容采取暂缓公开、退回补充或隔离处理，并提供勘误、申诉和撤回渠道。

</div>
