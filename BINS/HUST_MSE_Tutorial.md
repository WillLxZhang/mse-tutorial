# 项目名称（暂定）：华科机械入门指南（MSE_Tutorial）

## 一、我们的目标:
```
信息差永远存在。
我们希望能够搭建一个平台，给同学们一个入门——任何领域，学习以内、学习以外
    如果你刚刚进入大学，这里有你想探索的大学生活
    如果你对大学生活初窥门径的同学们，你或许能找到提升自己的答案
   如果你处于升学等关键节点，这里可以帮你参考：我该去往哪些地方？
希望能够给同学们一个契机，对自己现有的认识进行补充，获得更广阔的视野，能够更从容地规划和管理自己的大学生活。
```

## 二、主要参考：
1.深大飞跃手册：https://szu-feiyue.github.io/

2.Embodied AI Guidance：https://github.com/TianxingChen/Embodied-AI-Guide

## 三、建立规划
### **1.内容板块**
#### 主页：如何使用本指南

#### 板块一：不同发展路径经验分享（初版：征集、收集、筛选汇总、公开）
**过来人的个人故事** 希望涵盖的内容：待扩充
**四个子版块：** 保研；考研；留学；就业：
**可以由每一页中的关键词链接到子页面：竞赛 & 团队 & 课题组——这些东西的内容**
```
需要考虑的问题：
是否具有引导性？
内容是否爆
```

#### 板块二：技能栈（二版）：不同方向的介绍及其所需要的技能
学习资料/推荐书籍/网课资源。

#### 板块三：FAQ（前两个板块成熟了之后再考虑）
问题收集、汇总、筛选、解答与公开。
```
需要考虑的问题
这一流程的效率是否高
```

#### 板块四：生活板块：（前两个板块成熟了之后再考虑）
华科校内自习、活动还有周边美食玩乐好去处


### **2.人员需求：**
板块一：四个子版块各2人，一人收集一人汇总编排；共8人
其他版块：6人
Page搭建：3人
其他（还没想好）：2人


### **3.计划的演进路线**

#### 第一阶段（收集/汇总）：
面向学院20-23级的同学进行各个板块的内容收集，筛选与编排

#### 第二阶段（低成本搭建试运行）：
利用类似语雀等在线文本编辑软件收集 & 预编辑，用 Markdown + GitHub Pages 搭建最小可用网站，先上线，简单宣传并收集反馈意见。
#### 第三阶段（内容丰富化）：
不断收集更多的内容，并进行优化，正式面向大家来宣传。

#### 第四阶段（社区化）：
吸纳更多人参与贡献，增加**Q&A**,争取变成一个小社区。
